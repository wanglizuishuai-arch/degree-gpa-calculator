# 学位课均分与绩点计算器

一个**单文件、离线可用**的学分加权均分与绩点计算器。双击 `index.html` 即可使用，不需要联网、不需要安装任何东西。

专为**南通大学杏林学院**（绩点规则沿用南通大学本部）的成绩口径设计，也支持改成其他学校的规则。

---

## 计算口径

- **学分加权均分** = Σ(成绩 × 学分) ÷ Σ学分
- **平均学分绩点（GPA）** = Σ(单科绩点 × 学分) ÷ Σ学分

两个指标都按学分加权，不是简单平均。

## 功能

- **成绩栏直接写等级**：填「良好」「优秀」「中等」这类等级词，自动按学校标准折算成百分制，格子下方会标出折算结果
- **三种绩点换算方式**：线性公式（通大用这种）、分段映射（4.0 制学校）、直接手填单科绩点
- **单科绩点可手改**：补考课、重修课按学校规定单独记绩点，改过的格子会变黄并保留，旁边有「重算全部绩点」可一键清除
- **批量粘贴导入**：从 Excel / WPS 直接复制「课程名 学分 成绩」三列贴进来即可，制表符、逗号、空格都能识别
- **计入开关**：不算的课勾掉即可，不用删行
- **自动校验**：缺成绩或缺绩点的课会明确提示，不会按 0 分把结果算歪
- **本地保存**：数据只存在你自己的浏览器里（localStorage），关掉页面还在

## 南通大学杏林学院换算规则

百分制课程：

```
课程绩点 = (成绩 − 50) ÷ 10
```

即 60 分 = 1.0，每多 1 分加 0.1，满分 100 分 = 5.0。

五级记分（等级制）折算百分制：

| 五级记分 | 折算百分制 | 绩点 | 对应百分制区间 |
| --- | --- | --- | --- |
| 优秀 | 95 分 | 4.5 | 90～100 |
| 良好 | 85 分 | 3.5 | 80～89 |
| 中等 | 75 分 | 2.5 | 70～79 |
| 及格 | 65 分 | 1.5 | 60～69 |
| 不及格 | 50 分 | 0 | < 60 |

> 依据：《南通大学杏林学院 2026 届毕业班学位课程设置与说明》《南通大学全日制普通本科生学籍管理规定》第二十三条。

**补考提示：** 成绩不及格后补考通过的课程，绩点**不看实际得分**——百分制课程记 `1.0`、五级记分课程记 `1.5`，补考仍不及格记 0。这类课请在「单科绩点」列直接改。

## 使用方法

1. 下载或克隆本仓库，双击 `index.html` 用浏览器打开
2. 点「清空重填」清掉示例数据
3. 把课程贴进「批量粘贴」框（从 Excel 直接复制三列），点「导入并替换表格」
4. 底部立刻显示总学分、学分加权均分、平均学分绩点
